# Agent Failure Attribution

**Capstone Project | AIML**

## About

This repository contains the research documentation, project proposal, presentation materials, and implementation artifacts for our capstone project on failure attribution in LLM-based agents.

The project investigates whether human-identified causes of agent failures hold up under controlled replay experiments, how attribution varies across agents and repeated runs, and whether a lightweight verifier can help predict which failure explanations are supported by evidence.

## Project Status

**Phase:** Research and project planning

Currently, this repository contains the initial project documentation and presentation materials. Experimental protocols, implementation, and evaluation will be added as the project progresses.

## Research Focus

- **Attribution validity:** Do proposed causes of failure hold up when tested through controlled replays?
- **Reliability:** How much do attribution results vary across agents and repeated runs?
- **Verification:** Can a lightweight verifier predict whether a proposed failure explanation is supported by experimental evidence?
